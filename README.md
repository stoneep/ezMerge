1. 변형 프로필
   단순한 평면 B에 A를 붙여서, 원하는 접착 곡선과 실루엣부터 확인. Boolean·Spread·Relax·노멀 동기화는 끄고 시작.
2. 세분화 방식과 순서
   같은 변형에 선형 세분화와 Catmull?Clark을 비교하고, 변형 전·후 배치도 비교. 영상의 둥근 형상을 설명하는지 확인.
3. 접촉 위치
   프로필이 안정된 다음 곡면 B로 바꿔서 밀착·관통·이동 중 튐을 검증.
4. 노멀 연결
   형상을 확정한 뒤 노멀 보정을 켜서, 실제 곡면 개선과 음영으로 감춰지는 부분을 구분.
우선 목표는 ‘평면에 붙는 A 하나를 원하는 모양으로 만드는 것’이야. 여기서 프로필과 세분화의 역할을 확인하면, 복잡한 Cylinder 교차에서 무엇이 문제인지 초점을 맞출 수 있음

평면 접착 장면에서 프로필 검증을 마쳤어. 현재 Smooth 가중치가 부드럽다고 해서 최종 접합 단면도 평면에 부드럽게 이어지는 것은 아니었어.
Boolean·Spread·Relax·노멀 동기화를 끄고 같은 설정으로 비교했어. 접촉부 첫 구간과 평면 사이의 측정 각도는:
- Smooth: 약 75°
- Linear: 약 73°
- Sharp: 약 2.5°
- Sphere: 약 86°
- 기본 Custom Curve: 약 10°
이는 이번 설정과 측정 간격에서의 값이야. 실제 렌더에서도 Smooth는 가파른 받침대 형태, Sharp는 평면으로 넓게 퍼지는 형태가 나타났어.
Blender 4.2.1·5.1.2에서 원본 연결 구조 보존, 범위 밖 정점 유지, 접촉 위치 유지, 이동·복귀 테스트를 통과했어.
다음은 가중치 이름이 아니라 최종 반경·높이 곡선의 접선 조건을 기준으로 프로필을 정리하는 게 맞아. 기본 애드온은 변경하지 않았어.

평면에 자연스럽게 이어지는 비교용 Smooth 프로필을 만들고 검증했어.
- 접촉부 각도: 기존 약 75° → 7.3°
- 더 촘촘한 측정에서는 약 1.9°
- 원래 Cylinder로 돌아오는 경계의 방향 차이: 약 0.07°
Boolean·Spread·Relax·노멀 동기화 없이, 프로필 식만 바꾼 결과야. Blender 4.2.1·5.1.2에서 원본 보존과 이동·복귀 테스트도 통과했어.
렌더에서도 평면으로 퍼지는 형태가 개선됐지만, 작은 접촉부 음영 자국은 남아 있어. 아직 평면 검증용이며 기본 애드온에는 적용하지 않았어.

비교를 마쳤어. 세분화 효과와 원본 노멀 샘플링 문제를 분리할 수 있었어.
- 선형 세분화 후단: 접촉 반경·평면 위치 유지. 이번 장면에서 약 10~13ms.
- Catmull–Clark 후단: 영상처럼 위쪽 실루엣이 둥글어짐. 하지만 접합부가 수축하고, 접촉 둘레가 평면에서 약 0.05 들림.
- Catmull–Clark 전단: 원본의 바닥 경계부터 둥글어져, 밀착 계산에 들어오는 조건 자체가 달라짐.
또한 원본 정점 노멀을 직접 읽자 접촉부의 삼각형 틈이 사라졌어. Boolean 없는 비교 경로에서 최근접 노멀 샘플링이 별도 문제를 만들고 있었던 거야.
Blender 4.2.1·5.1.2에서 검증했고, 기본 애드온은 변경하지 않았어.
다음은 원본 정점 노멀 + 변형 + Catmull–Clark 후단을 고정하고, 세분화로 들린 접촉부만 재밀착하는 비교야.


점진적인 재밀착 방식이 더 나은 결과를 냈어.
- 접촉 둘레의 간격: 약 0.05 → 0
- 접촉부 구간 각도: 강제 투영 35.8°, 점진 보정 6.4°
- 세분화 레벨 3에서는 점진 보정 각도가 **2.4°**로 줄어듦.
Blender 4.2.1·5.1.2에서 원본·연결 구조 보존, 이동·복귀, 보정 범위 밖 위치 유지도 확인했어. 테스트 장면의 전체 평가 시간은 약 11~12ms였어.
다만 Catmull–Clark으로 줄어든 접합 폭과 경계 음영은 남아 있어. 아직 평면 비교용이며 기본 애드온은 변경하지 않았어.
다음은 이 형상을 고정하고 노멀 연결만 켜서 남은 경계가 얼마나 줄어드는지 확인하는 단계야.

노멀 연결만으로는 남은 접촉선을 없애지 못했어.
Blender 5.1에서 확인한 결과:

따라서 남은 경계는 노멀 불일치만의 문제가 아니야. 하부 곡면이 떠 있는 구간과 평면에 겹친 면을 따로 검증해야 해.

이번 검증에서는 노멀뿐 아니라 접촉부 형상에도 하향 면이 남아 있음을 확인했습니다.
- 노멀을 뒤집지 않는 방향 제한 방식은 블록형 음영을 피했지만, 얇은 경계선은 남았습니다.
- 평면 테스트에서 접합부 주변 코너 1,536개 중 1,024개의 실제 면 노멀이 아래를 향했습니다. 단순 노멀 동기화만으로 해결하기 어려운 상태입니다.
